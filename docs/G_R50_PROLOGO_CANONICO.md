# G-R50 — prólogo canónico del usuario

La redacción de `traduccion/PROLOGO_GRAFICO_ES.txt` sustituye a la propuesta R49 para toda futura integración gráfica. Se conserva la redacción del usuario, incluso la minúscula de «Arcanus cella»; solo se ajustaron puntuación y comillas. El texto se divide en ocho renglones sin añadir puntos por salto visual.

La textura ANIME000.IDT / IMY192, registro 188, 256×128, fue reconstruida a 4308 bytes exactos, dos bytes de cola preservados, con fuente Noto Serif ExtraCondensed Bold 11 px. ISO diagnóstica privada de 305496064 bytes, SHA-256 e3998fb70a8b65eb07fb83cb16f261c7ddf3cc03a37c1c09b72f1439457f2734. Comparación completa: 4228 bytes distintos exclusivamente en el slot original, otros 230 flujos IDT y 348 PSPFS intactos. PIC0.PNG se reeditó con las tres líneas finales canónicas; aún no se reinserta porque aumenta 7410 bytes. El ZIP R50 privado reproduce 53/53 hashes comprimidos; 51 idénticos a R49, solo cambian prólogo y PIC0. No se publicó ISO ni recurso comercial.

Usar exclusivamente el paquete R50 de SHA-256 785dbceeda29b489e3373ee5427de1a01b422f68e45bedd1fe3aa9fc5e6925b5. Los nombres internos R49 se mantienen por compatibilidad del reproductor.
